### 🚀 Featured work

#### [Brahmastra](https://github.com/ShaanKapoor10/vaultgraph-qy) — knowledge-graph memory for AI agents (MCP + GraphRAG)

A self-hosted memory layer that any MCP client (Claude Code, Cursor, custom agents) plugs into. It turns notes, code, documents and past agent sessions into a cited knowledge graph that persists across sessions and machines.

| What I measured | Result |
| --- | --- |
| Claude coding agent, 15 repository tasks | **37% lower cost**, 46% fewer fresh input tokens, **0 wrong answers** |
| Retrieved memory vs pasting the whole knowledge base | **34/35 vs 30/35** correct with **13.7× fewer tokens** |
| LoCoMo long-conversation memory benchmark | 67% vs 73% for full context, at **6× fewer tokens** |
| Knowledge graph built from 146 notes | **1,736 cited facts**, **1,440 resolved entities** |
| Hybrid search (Postgres full-text + pgvector) | **64 ms p95** |

`Python` `FastAPI` `Neo4j` `PostgreSQL/pgvector` `MCP` `Next.js` · 12 MCP tools · 40 REST endpoints · 1,040 tests
